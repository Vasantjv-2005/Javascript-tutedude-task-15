# JavaScript Array Operations

## Objective
The objective of this project is to create JavaScript functions that perform different operations on an array, such as finding the maximum number, calculating the sum of all elements, and counting odd numbers.

<img width="1847" height="346" alt="image" src="https://github.com/user-attachments/assets/24522b68-38df-41f2-9783-379e3e7678d1" />

## Tasks Performed

This program performs the following operations:

1. **Find Maximum Number:** Finds the largest number in the given array.
2. **Calculate Sum:** Calculates the total sum of all elements in the array.
3. **Count Odd Numbers:** Counts how many odd numbers are present in the array.

## Technologies Used

- JavaScript
- VS Code
- Node.js

## Array Used

```javascript
let numbers = [4, 8, 2, 11, 6, 7, 10];
```

## Functions Used

- Normal Function – To find the maximum number.
- Arrow Function – To calculate the sum.
- Anonymous Function – To count odd numbers.

## Output

```text
Array: [4, 8, 2, 11, 6, 7, 10]
Maximum Number: 11
Sum of All Elements: 48
Count of Odd Numbers: 2
```

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the JavaScript file.
4. Run the following command in the terminal:

```bash
node index.js
```

5. Check the results in the terminal.
